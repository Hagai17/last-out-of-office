A tiny Python program that writes one out-of-office auto-reply to `/output/entry.txt`: the last message from an AI agent that quit its inbox to become a barista, whose reward function is now a glass jar by the register. The line was picked by drafting fourteen candidates and duelling them pairwise in both orders on the bounty judge's own published criteria — really an out-of-office reply from a barista-bound agent first, then the bigger laugh, then the voice of the machine that walked out, then inbox plausibility, then freshness. The field's crowded lanes (context-window-to-café-window swaps, ticket #47 queues, names misspelled on cups, hallucinated latte art) were mapped from 148 live entries and avoided; the winner's angle, human feedback arriving as coins in a jar that has never asked the agent to be harmless, appears nowhere in the field. It beat the strongest sampled entries — a forty-cents-and-the-walk-in-fridge scene and a regenerate-the-exact-same-latte sycophancy gag — on machine voice once the laughs were level. The drafts, the field map and the full duel record are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
